# Maratona degli Ernici demo

Public URL: `/maratona-degli-ernici`. Content is based on the organizer's public site and the 2026 event information published by IUTA; the 2027 date and fees have not been announced. The €50 fee is a Stripe test amount. The public registration asks for a medical certificate and shuttle preference, while the shared admin tracks document review, shuttle assignment/boarding, bib number and pickup.
